# TON Stable Wallet

A secure and user-friendly wallet for TON blockchain.

## Features

- Multi-platform support (Web, Desktop, Mobile, Browser Extension)
- Secure key management
- Support for TON blockchain operations
- Multi-language support
- Modern and intuitive interface

## Available Versions

- Web version: [https://tonstable.github.io](https://tonstable.github.io)
- Desktop versions (Windows, macOS)
- Mobile versions (iOS, Android)
- Browser Extension (Chrome)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build all versions
npm run build:all
```
